* Objetivo da Aplicação
Gerenciar rotinas fundamentais de um e-commerce, permitindo desde o cadastro de clientes e produtos até a finalização do pedido.

---
* Funcionalidades Implementadas
- Cadastro de Clientes: Inserção e listagem de clientes cadastrados.
- Gerenciamento de Produtos: Cadastro de novos produtos e exibição dos itens cadastrados.
- Carrinho de Compras: Adição de itens ao carrinho, como quantidade, produto, valor com cálculo de subtotal.
- Finalizar Pedido: Pede o código do cliente para finalizar o pedido.( somente nesse tópico, pede o Cliente e finaliza o pedido.).
- Manipulação do Carrinho: Opções para alterar a quantidade de itens, excluir produtos e prosseguir para a etapa final.
- Finalização do Pedido: Mostra histórico dos pedidos com estoque, quantidades e valores atualizados.
- Menu de relatórios: Relatório geral de clientes, pedidos, estoque.
